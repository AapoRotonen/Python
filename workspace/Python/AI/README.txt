AI Knowledge Base Agent

Tämä projekti osoittaa, miten rakennetaan tietopohjainen tekoälyagentti (RAG), joka kykenee vastaamaan kysymyksiin spesifin dokumentaation perusteella.

Teknologiat: Python, LangChain, OpenAI, ChromaDB.



Tämä ratkaisee ongelman, jossa kielimalli "hallusinoi" tai ei tiedä yrityksen sisäisestä tiedosta.
